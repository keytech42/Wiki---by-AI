# 20260715_TPU_Systolic_Array_Study

## Overview
- **Objective:** 딥러닝의 핵심 연산인 행렬 곱셈($C = A \times B$)이 실제 하드웨어(TPU)의 Systolic Array에서 어떻게 물리적으로 처리되는지, Python 기반 하드웨어 시뮬레이터 구현 과정을 통해 분석한다.
- **Why:** 수식이나 고차원 프레임워크(PyTorch) 레벨의 추상화를 벗어나, 하드웨어의 클럭 엣지(Clock Edge) 단위로 데이터가 어떻게 이동하고 계산되는지 그 바닥의 원리를 직관적으로 이해하기 위함이다.

## Context & Discovered Concepts
이 세션에서는 추상적인 수학 연산을 제한된 크기의 물리적인 2차원 연산기 배열로 매핑하는 과정에서 발생하는 인지적 간극을 좁히는 데 집중했다. 

1. **[[Systolic Array Spatial-Temporal Mapping]]**
   - 가중치 행렬 $B$가 하드웨어 배열에 고정(Stationary)되어 있을 때, 거대한 입력 행렬 $A$는 어떻게 투입되어야 할까? 
   - 하드웨어의 물리적 크기 한계를 극복하기 위한 타일링(Tiling)의 필요성을 짚고, $A$ 행렬이 하드웨어 규격에 맞춰 차원을 뒤집고(Transpose), 데이터 충돌을 막기 위해 시간차를 두어 계단식으로 밀어넣는(Skewing) 매핑 원리를 확인했다. 이 과정에서 파생된 파이프라인 딜레이 계산식과 통합 멘탈 모델을 정리했다.
   
2. **[[Shift Register Abstraction in NumPy]]**
   - 하드웨어 아키텍처를 스크립트 단에서 구현할 때 가장 큰 장애물은, 하드웨어의 시간 흐름(Clock)을 Python이라는 소프트웨어 언어가 어떻게 시뮬레이션하는가였다.
   - 시뮬레이터에 등장하는 복잡한 배열 슬라이싱(`[:, 1:] = [:, :-1]`)은 단순한 데이터 복사가 아니라, 하드웨어의 시프트 레지스터(Shift Register)가 매 클럭마다 데이터를 가로/세로로 한 칸씩 밀어내는 물리적 전압 이동을 추상화한 것임을 규명했다.
