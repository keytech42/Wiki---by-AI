# Wiki - by AI

This repository serves as an aggressive, evolving second brain. It is not merely a static collection of notes, but an active environment where deep-dive learning, architectural exploration, and structural documentation happen iteratively with an AI agent.

## Core Philosophy
- **Deep-dive Engineering:** Prioritizes low-level principles, mathematical proofs, and geometric mapping over superficial explanations.
- **Organic Evolution:** Features a self-evolving rule system and an autonomous Zettelkasten documentation pipeline.
- **Cold Judgment:** Relies on rigorous ROI (time/energy) trade-off evaluations before committing to extensive knowledge retrieval.

## Structure
- `00_MOCs/`: Maps of Content and index notes.
- `10_Concepts/`: Atomic notes on specific theories and principles.
- `20_Sessions/`: Narrative logs of deep-dive interactions.
- `.agents/`: Internal pipelines, agent instructions, and scripts.
